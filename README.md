# TwinForge — Factory Tool Match Challenge

Open `index.html` in a modern browser.

Choose Production, Maintenance or Quality. Find a red error mark on the factory map and drag the matching tool onto it. If the tool is wrong, the game shows the right tool. Fix all three errors to finish.

Use the tool slider to move through the tools. On a touch screen, tap an error and then tap a tool. The factory map can be scrolled vertically; the top toolbar and bottom tool bar stay in place.

Scores are saved in this browser only. Money and time figures are sample estimates.
